# 🍉 Fruit Ninja AR — Motion Hand-Tracking Web Game

A high-performance, browser-based **Fruit Ninja** mini-game featuring **real-time AI hand-tracking motion controls** powered by MediaPipe and Web Audio procedural sound synthesis.

---

## ✨ Features

- **🎮 AI Webcam Hand Tracking**: Slice fruits mid-air using webcam hand gestures and finger velocity tracking.
- **🖱️ Mouse & Touch Fallback**: Smooth cursor and touchscreen slicing support.
- **⚔️ Unlockable Blade Skins**: Cyber Katana, Dragon Flame, Sakura Blossom, Shadow Void, Solar Radiance, and Prism Rainbow.
- **🏮 Dojo Themes & AR Pass-through**: Tatami Dojo, Cyber Neon Dojo, Sunset Pagoda, and Live Webcam Camera AR background.
- **🍌 Power-up Fruits & Hazards**: Matrix Freeze Banana, Dragonfruit Frenzy, Double Score Starfruit, and Bombs.
- **🎵 Procedural Web Audio**: Real-time sound effects (squishes, slashes, explosions, chords, and zen ambient chimes) with zero external audio assets.
- **📊 Detailed Game Analytics**: Combos, accuracy, slicing heatmaps, and high score tracking.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🕹️ Controls

- **Webcam Mode**: Hold your hand up to the camera and perform slicing motions across fruits.
- **Mouse / Touch Mode**: Click/touch and drag across the screen to slice.
- **Escape / ESC**: Pause or return to the menu.
